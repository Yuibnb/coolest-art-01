# Coolest Art — "Lantern Koi"

A colossal golden koi swims through the night sky above a sleeping city.
Its scales glow like lit windows, mirroring the city lights far below —
one fish, one city, one night.

`main.py` (Python 3.13, standard library only) copies `entry.png`
beside it to `MAKEFUN_OUTPUT_DIR` (or `/output`), byte for byte.
The entry runs twice and writes identical bytes both times.

No text, no watermark, no borrowed artwork: the image was generated
fresh for this entry.
