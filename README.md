# Coolest Art — "Knitting the Moon"

A tiny worker on a bamboo scaffold knits moonlight into the sea.
A giant cracked moon, mended with gold, hangs over indigo waves —
one moon, one worker, one impossible task.

`main.py` (Python 3.13, standard library only) copies `entry.png`
beside it to `MAKEFUN_OUTPUT_DIR` (or `/output`), byte for byte.
The entry runs twice and writes identical bytes both times.

No text, no watermark, no borrowed artwork: the image was generated
fresh for this entry with code (Python PIL + numpy, seeded).
